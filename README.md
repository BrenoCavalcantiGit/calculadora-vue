# Calculadora com Vue.js

Calculadora aritmética feita com Vue 3 (via CDN):

- dois campos numéricos e um `select` com a operação
- o resultado é calculado automaticamente (reatividade com `computed`)
- renderização condicional (`v-if`), listas (`v-for`), estilo condicional (`:class`) e componente com props

Para usar, abra o `index.html` no navegador (precisa de internet para carregar o Vue).
